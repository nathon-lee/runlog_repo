# DeepSpeed AutoEP (PR #7938) 个人双卡测试指南

本指南用于协助 DeepSpeed PR #7938 作者 `@tohtana` 测试处于实验阶段的 **AutoEP (自动专家并行)** 功能。
测试目标：在消费级/较便宜的 2x GPU（如 RTX 3090, A10）上跑通预设模型（如 Qwen3-MoE 或 DeepSeek），验证分布式路由通信逻辑。

## 1. 准备代码环境

首先，克隆作者包含 AutoEP 功能的 DeepSpeed 分支，以及配套的测试用例仓库。

```bash
# 1. 安装 DeepSpeed (AutoEP 测试分支)
git clone -b tohtana/add_autoep https://github.com/tohtana/DeepSpeed.git
cd DeepSpeed
pip install -e .
cd ..

# 2. 克隆并准备测试用例
git clone -b tohtana/add_auto_ep https://github.com/tohtana/DeepSpeedExamples.git
cd DeepSpeedExamples/training/expert_parallel
pip install -r requirements.txt
```

## 2. 修改测试代码 (以测试 Qwen-MoE 为例)

为了让模型能塞进小显存，同时**不破坏 HuggingFace 模型的内部维度一致性**，我们选择官方的 `Qwen1.5-MoE-A2.7B` 配置，仅仅将层数（`num_hidden_layers`）砍到 2 层。

### 修改一：`train_compare.py`
编辑 `train_compare.py`，在大约第 22 行增加 `AutoConfig` 的导入：
```python
import torch
from transformers import AutoModelForCausalLM, AutoConfig
```

找到第 308 行附近，将原本用于生成 `Mixtral` 配置的代码注释掉，替换为以下 Qwen 的安全缩小版配置：

```python
    # Build model config
    output_router_logits = args.include_router_aux_loss == "on"
    
    # --- 替换为 Qwen-MoE 配置 ---
    model_config = AutoConfig.from_pretrained("Qwen/Qwen1.5-MoE-A2.7B", trust_remote_code=True)
    # 仅缩小层数防止 OOM，绝对不要修改 hidden_size 等维度，否则会导致 HF 初始化报错
    model_config.num_hidden_layers = args.num_layers  
    
    # Qwen MoE 的专家参数提取
    num_experts = model_config.num_experts
```

### 修改二：`configs/ds_autoep_zero1.json`
修改 DeepSpeed 配置文件，将预设模型改为 `qwen3-moe`，并将 `autoep_size` 改为你机器上的 GPU 数量（例如 2）。

```json
{
  "expert_parallel": {
    "enabled": true,
    "autoep_size": 2,
    "preset_model": "qwen3-moe",
    "load_balance_coeff": null
  },
  ...
}
```

## 3. 运行测试命令

在 `training/expert_parallel` 目录下运行以下命令（指定 `--num_gpus 2` 和 `--num_layers 2`）：

```bash
deepspeed --num_gpus 2 train_compare.py \
    --mode autoep \
    --deepspeed_config configs/ds_autoep_zero1.json \
    --num_layers 2 \
    --steps 50 \
    --seq_len 128 \
    --micro_batch_size 2
```

## ⚠️ 避坑指南：为什么之前测试 DeepSeek 会报 `head_dim` 错误？
之前尝试强行修改 `hidden_size = 512` 和 `intermediate_size = 1024` 来压缩 DeepSeek-V2。这破坏了模型注意力机制（MLA）内部的维度推导逻辑（如 `qk_head_dim`、`v_head_dim`），导致在 HF 实例化阶段就崩溃了，根本没进入 DeepSpeed 的测试环节。
**结论**：制作 Toy Model 测试时，**只改 `num_hidden_layers` 是最安全的做法**。
